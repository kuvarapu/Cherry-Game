## 🎯 Quick Deploy (5 Minutes Total)

### Step 1: Deploy Backend (2 minutes) - Render.com

**Click here to deploy:** https://dashboard.render.com/select-repo?type=web

1. **Sign in** with GitHub
2. **Select repository:** `kuvarapu/Cherry-Game`
3. **Render auto-detects** the configuration from `render.yaml`
4. **Click "Create Web Service"**
5. **Add Environment Variables:**
   - Click "Environment" tab
   - Add these:
     ```
     MONGODB_URI = mongodb+srv://cherrygame:PASSWORD@cluster0.xxxxx.mongodb.net/cherry-game
     JWT_SECRET = (auto-generated by Render)
     FRONTEND_URL = https://cherry-game.vercel.app
     CORS_ORIGIN = https://cherry-game.vercel.app
     ```

**Your backend URL will be:**
```
https://cherry-game-backend.onrender.com
```

### Step 2: Create Database (3 minutes) - MongoDB Atlas

**Click here:** https://www.mongodb.com/cloud/atlas/register

1. **Create account** (free)
2. **Create FREE M0 Cluster** (512MB)
3. **Database Access** → Add New User:
   - Username: `cherrygame`
   - Password: (auto-generate and save it)
   - Role: Atlas admin
4. **Network Access** → Add IP:
   - Click "Allow Access from Anywhere" (0.0.0.0/0)
5. **Connect** → Drivers → Copy connection string:
   ```
   mongodb+srv://cherrygame:<password>@cluster0.xxxxx.mongodb.net/cherry-game
   ```
6. **Paste into Render** environment variable `MONGODB_URI`

### Step 3: Deploy Frontend (1 minute) - Vercel

**Option A - One Click:**

Click here: https://vercel.com/new/clone?repository-url=https://github.com/kuvarapu/Cherry-Game

**Option B - Command Line:**

Run in PowerShell:
```powershell
vercel login
# Press ENTER and login in browser
vercel --prod
```

Follow prompts:
- Link to existing project? **No**
- Project name? **cherry-game** (or press Enter)
- Directory? **./** (press Enter)
- Override settings? **No**

**Your frontend URL will be:**
```
https://cherry-game.vercel.app
```

## ⚠️ Important Notes

### First Load (Render Free Tier)
- Backend sleeps after 15 minutes of inactivity
- First request takes ~30 seconds to wake up
- After that, it's fast!

### Update Backend URL
If your Render backend has a different URL, update it:

1. Edit `frontend/public/config.js`:
   ```javascript
   API_URL: 'https://YOUR-ACTUAL-BACKEND.onrender.com/api'
   ```
2. Redeploy:
   ```powershell
   git add .
   git commit -m "Update backend URL"
   git push
   vercel --prod
   ```

## 🌐 Custom .in Domain (Optional)

### On Vercel:
1. Dashboard → Your Project → Settings → Domains
2. Add `cherrygame.in`
3. Update DNS (at your domain registrar):
   ```
   Type: CNAME
   Name: @
   Value: cname.vercel-dns.com
   ```

### On Render:
1. Dashboard → Your Service → Settings → Custom Domain
2. Add `api.cherrygame.in`
3. Update DNS:
   ```
   Type: CNAME
   Name: api
   Value: cherry-game-backend.onrender.com
   ```

**Final URLs:**
- `https://cherrygame.in` - Frontend
- `https://api.cherrygame.in` - Backend

## 🆘 Troubleshooting

### "Cannot connect to backend"
- Check backend is running: `https://cherry-game-backend.onrender.com/api/health`
- Verify `frontend/public/config.js` has correct backend URL
- Check CORS_ORIGIN in Render matches your Vercel URL

### "Database connection failed"
- Verify MongoDB connection string in Render environment variables
- Check MongoDB Atlas IP whitelist (0.0.0.0/0)
- Ensure database user password is correct

### Backend is slow on first load
- Normal for Render free tier (wakes from sleep)
- Keep-alive services can ping your backend every 10 minutes
