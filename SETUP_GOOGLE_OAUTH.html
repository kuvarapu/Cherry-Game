🍒 Google OAuth Setup

Follow these steps to enable "Sign in with Google"

⚠️ Google OAuth is not configured yet. Follow the steps below to set it up.

📋 Step 1: Create Google Cloud Project

  1. Go to Google Cloud Console
  2. Click "Create Project"
  3. Name it Cherry Game
  4. Click "Create"

🔐 Step 2: Create OAuth Credentials

  1. In Google Cloud Console, go to "APIs & Services" → "Credentials"
  2. Click "Create Credentials" → "OAuth client ID"
  3. If prompted, configure the OAuth consent screen:
    • Choose "External" user type
    • Fill in App name: Cherry Game
    • Add your email as support email
    • Add scopes: email and profile
    • Add yourself as a test user
  4. Back to Credentials, choose "Web application"
  5. Name: Cherry Game Web Client
  6. Add Authorized redirect URIs:
    7. http://localhost:4000/api/auth/google/callback
  7. Click "Create"
  8. 📝 Copy the Client ID and Client Secret

⚙️ Step 3: Configure Backend

Option A: Using .env file (Recommended)

  1. Create a file named .env in the backend folder
  2. Add your credentials:
    3. GOOGLE_CLIENT_ID=your_client_id_here.apps.googleusercontent.com GOOGLE_CLIENT_SECRET=your_client_secret_here JWT_SECRET=your_secret_key_here PORT=4000 GOOGLE_CALLBACK_URL=http://localhost:4000/api/auth/google/callback

Option B: Direct in config.js

  1. Open backend/config.js
  2. Replace the placeholder values with your actual credentials

🚀 Step 4: Restart Backend

  1. Stop the current backend server (Ctrl+C)
  2. Restart it:
    3. cd backend node server.js

✅ Step 5: Test It!

  1. Go to http://localhost:8080
  2. Click "Sign in with Google"
  3. Select your Google account
  4. Grant permissions
  5. You should be logged in automatically! 🎉
